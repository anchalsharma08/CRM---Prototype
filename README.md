# Azisly.ai CRM Prototype

A standalone, static CRM prototype built with HTML, CSS, and JavaScript. No build tools or external packages are required.

## Run locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html` (or upload the contents of this ZIP).
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will provide a public URL after deployment completes. It usually looks like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Notes

- The prototype uses in-memory demo data. Changes and uploaded payment proof images reset when the page is refreshed.
- WhatsApp sharing opens a prefilled message for the selected customer.
- Product descriptions and payment records are demo content.
